# Helper

A local-first AI assistant with persistent memory, autonomous agent capabilities, and a rich web UI. Built with React, Express, [Together.ai](https://www.together.ai/) LLMs, and [Mem0 OSS](https://docs.mem0.ai/open-source/overview) for semantic memory.

## Features

### Core
- **Multi-profile chat** with Together.ai models (auto-routing by complexity)
- **Persistent semantic memory** via Mem0 OSS (per-profile, SQLite history + in-memory vectors)
- **MCP tool integration** — connect HTTP or stdio MCP servers for function calling
- **Agent personas** — customizable personality, voice style, and system prompt per profile

### Agent Mode
- **Autonomous agent loop** — multi-turn execution with tool calls (opt-in via UI toggle)
- **15 built-in tools**: file read/write, bash terminal, glob, grep, web search (DuckDuckGo), web fetch, memory management, task planning (todo), delegation, learning tools, wiki
- **Real-time terminal** — agent shell commands stream to the UI via xterm.js
- **Multi-agent orchestration** — delegate subtasks to specialist sub-agents
- **Task planner** — structured task lists with status tracking

### Background Services
- **autoDream** — periodic memory consolidation engine (merges, deduplicates, indexes memories)
- **Autopilot** — proactive always-on observer (monitors stale tasks, overdue plans, memory health)
- **Model evaluation** — periodic dialog quality assessment, adaptive model ranking

### Teacher Mode
- **Learning plans** — structured syllabi generated by the agent
- **Lessons & quizzes** — interactive content with knowledge testing
- **Progress tracking** — per-plan completion metrics
- **Wiki / Knowledge base** — agent-maintained articles with search

### Frontend
- **VS Code-like layout** — sidebar navigation, bottom panel (terminal, tasks, agent log)
- **Chat session history** — server-backed, with auto-save and localStorage migration
- **Slash commands** — `/compact`, `/dream`, `/autopilot`, `/tasks`, `/learn`, `/wiki`, `/persona`, `/context`
- **Real-time notifications** — dream status, Autopilot observations, agent progress
- **Persona selector & editor** — switch agent personalities from the UI
- **Analytics panel** — token usage, cost tracking, context window visualization

## Tech Stack

| Layer | Technology |
|-------|-----------|
| Frontend | React 19, Vite 8, Zustand, Socket.io client, xterm.js |
| Backend | Express 5, Vercel AI SDK, Socket.io |
| LLM Provider | Together.ai (OpenAI-compatible API) |

- **Node.js >= 20.19** (22.x recommended)

## Quick Start

```bash
# 1. Clone and install
git clone <repo-url> && cd helper
npm install

# 2. Configure
cp .env.example .env
# Edit .env and set TOGETHER_API_KEY

# 3. Run development servers
npm run dev
```

- **UI**: http://localhost:5173 (Vite dev server, proxies `/api` and `/socket.io` to backend)
- **API**: http://localhost:3001

## Production Build

```bash
# Build both server and web
npm run build

# Start production server (serves static UI from apps/web/dist)
npm start
```

The server automatically serves the built frontend when `apps/web/dist` exists.

## Configuration

All configuration is via environment variables. See [`.env.example`](.env.example) for the full list.

| Variable | Required | Description |
|----------|----------|-------------|
| `TOGETHER_API_KEY` | Yes | Together.ai API key for chat, embeddings, Mem0 |
| `MONGODB_URI` | No | MongoDB connection string (profiles + MCP config; falls back to JSON files) |
| `WEB_ORIGIN` | No | CORS origin (default: `http://localhost:5173`) |
| `PORT` | No | Server port (default: `3001`) |
| `TOGETHER_BASE_MODEL` | No | Base chat model (default: `google/gemma-3n-E4B-it`) |
| `MAX_TOOL_ROUNDS` | No | Max tool call rounds per request (default: `8`) |
| `DREAM_MIN_INTERVAL_HOURS` | No | Min hours between auto-dream runs (default: `6`) |
| `DREAM_MIN_SESSIONS` | No | Min agent sessions before dream triggers (default: `3`) |
| `EVAL_EVERY_N_SESSIONS` | No | Evaluate model quality every N sessions (default: `5`) |

## API Endpoints

### Chat & Models
- `POST /api/chat` — AI SDK streaming (compatible with `useChat`)
- `GET /api/models` — available Together.ai models

### Profiles & Memory
- `GET|POST|PATCH|DELETE /api/profiles` — memory profiles
- `GET|PATCH|DELETE /api/memory*` — inspect/edit/delete memories

### Agent Features
- `GET|POST|PATCH|DELETE /api/chat-sessions` — chat session history
- `POST /api/chat-sessions/import` — migrate localStorage chats
- `GET|PATCH|DELETE /api/tasks` — agent task management
- `GET|POST|PATCH|DELETE /api/personas` — agent personas

### Services
- `GET /api/dream/history` | `POST /api/dream/trigger` — autoDream
- `GET /api/autopilot/status` | `POST /api/autopilot/mode` | `GET /api/autopilot/observations` — Autopilot
- `GET /api/model-eval/rankings` — model evaluation rankings

### Teacher Mode
- `GET /api/learning/plans` | `GET /api/learning/progress/:planId` — learning
- `GET|POST|PATCH|DELETE /api/wiki` — knowledge base

### MCP
- `GET|POST|DELETE /api/mcp/servers` — MCP server config
- `POST /api/mcp/servers/:id/test` — test MCP server

## Resilience

The server is designed for frequent restarts during development:

- **Write-through persistence** — all data written to SQLite immediately (WAL mode)
- **Graceful shutdown** — `SIGINT`/`SIGTERM` handlers clean up child processes, release locks, stop timers
- **Startup recovery** — cleans stale locks, resets interrupted sessions and hung tasks
- **Heartbeat locks** — autoDream uses PID-based locking to prevent duplicate runs after crashes
- **Periodic Mem0 snapshots** — vector store state saved to disk for faster restart
